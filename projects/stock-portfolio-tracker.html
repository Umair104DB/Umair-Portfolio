Project Overview

Calculate estimated holding values and total portfolio value from symbols, quantities, and CSV reference prices.

Key Features

  • Read sample stock prices from CSV
  • Enter stock symbols and quantities
  • Look up reference prices
  • Calculate individual holding values
  • Calculate total portfolio value
  • Validate entered symbols and quantities

Project Workflow

Load price CSV → Enter holdings → Match symbols → Calculate holding values → Sum portfolio value

Technologies Used

PythonCSVDictionariesFunctionsInput validation

Scope & Notes

Prices are static sample values unless a live market data provider is integrated. This is not investment advice or live market data.
