Project Overview

Demonstrate an educational credit-risk classification workflow using applicant data and a Random Forest model.

Key Features

  • Inspect applicant records
  • Prepare classification features
  • Train and evaluate a Random Forest classifier
  • Enter example applicant details
  • Display a predicted risk category
  • Explore results in a Streamlit interface

Project Workflow

Load applicant data → Prepare features → Train Random Forest → Evaluate model → Predict risk category

Technologies Used

PythonPandasNumPyScikit-learnRandom ForestStreamlitMatplotlib

Scope & Notes

Uses synthetic sample data. It is an educational demonstration and must not be used for real loan decisions or financial advice.
