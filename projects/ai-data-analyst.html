Project Overview

Ask questions about uploaded CSV and Excel data in natural language and receive AI-assisted analysis.

Key Features

  • Upload CSV and XLSX files
  • Preview rows and inspect column names
  • Basic type conversion and date parsing
  • Ask questions in natural language
  • Use DuckDB SQL and Pandas tools through an Agno agent
  • Display the agent response in Streamlit

Project Workflow

Upload dataset → Prepare data → Ask a question → AI agent uses data tools → View answer

Technologies Used

PythonStreamlitPandasDuckDBAgnoOpenAI GPT-4o

Scope & Notes

Requires an OpenAI API key and internet access. It performs basic preprocessing, not full data cleaning. It does not currently include a dedicated visualization dashboard, downloadable reports, or automated model training.
