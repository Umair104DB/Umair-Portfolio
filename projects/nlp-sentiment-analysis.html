Project Overview

Classify text reviews into sentiment labels using TF-IDF features and Logistic Regression.

Key Features

  • Load labelled review examples
  • Convert text into TF-IDF features
  • Train Logistic Regression model
  • Show sentiment distribution
  • Predict sentiment for entered text
  • Display classification report and test accuracy

Project Workflow

Load labelled reviews → Vectorize text → Train classifier → Evaluate model → Predict new review

Technologies Used

PythonPandasScikit-learnTF-IDFLogistic RegressionStreamlitPlotly

Scope & Notes

The repository uses short synthetic review examples. Results should not be treated as representative public opinion.
