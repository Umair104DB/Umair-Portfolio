Project Overview

Bundle small Python utilities for organizing image files, extracting email-like strings, and saving webpage titles.

Key Features

  • Move JPG and JPEG files into an organized folder
  • Skip duplicate destination filenames
  • Extract unique email-like strings from text files
  • Save extracted strings to a text file
  • Fetch a public webpage and save its title
  • Handle common file and request errors

Project Workflow

Choose a utility → Provide input → Process files or webpage → Save output → Review result

Technologies Used

PythonpathlibosshutilRegular expressionsRequestsBeautifulSoup

Scope & Notes

Test file operations on copies. Extracted email-like strings are not verified addresses or consent to contact. Respect website access rules.
