Project Overview

Classify text messages as spam or genuine using TF-IDF text features and a Multinomial Naive Bayes model.

Key Features

  • Interactive message tester
  • Filter and inspect dataset records
  • Show evaluation metrics and confusion matrix
  • Export dataset records to CSV
  • Download test predictions
  • Present model limitations and safety guidance

Project Workflow

Load labelled messages → Vectorize text → Train Naive Bayes → Evaluate classifier → Test a new message

Technologies Used

PythonPandasScikit-learnTF-IDFMultinomial Naive BayesPlotlyStreamlit

Scope & Notes

This is a demonstration classifier. Do not rely on it as the only control for security-sensitive message filtering.
