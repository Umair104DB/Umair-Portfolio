Project Overview

Retrieve permitted public webpage HTML and extract structured information such as headings and links.

Key Features

  • Accept a webpage URL
  • Send an HTTP request with Requests
  • Parse returned HTML using BeautifulSoup
  • Extract headings and links
  • Display or export collected information

Project Workflow

Enter public URL → Fetch HTML → Parse document → Extract headings and links → Review results

Technologies Used

PythonRequestsBeautifulSoupPandasStreamlit

Scope & Notes

Scrape only pages where automated access is permitted. Respect terms of service, robots.txt, rate limits, copyright, and privacy requirements.
