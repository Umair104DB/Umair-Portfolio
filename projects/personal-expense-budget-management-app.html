Project Overview

Record personal income and expenses, set monthly category budgets, and review balances in a Flask web app.

Key Features

  • Add income and expense transactions
  • Assign category, date, and optional description
  • Create or update monthly category budgets
  • View monthly income, expenses, and remaining balance
  • Delete transaction records
  • Export transactions to CSV
  • Store records with SQLAlchemy and SQLite by default

Project Workflow

Record transaction → Save to database → Set monthly budgets → Review monthly balance → Export CSV

Technologies Used

PythonFlaskFlask-SQLAlchemySQLitePostgreSQL-compatible configuration

Scope & Notes

The current app has no login or user-level data separation. Add authentication, CSRF protection, secure configuration, and persistent backups before using real sensitive financial data.
