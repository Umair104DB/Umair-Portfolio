Project Overview

Create a simple command-line chatbot that matches user messages to predefined rules and returns conversational replies.

Key Features

  • Accept text messages
  • Normalize user input
  • Match predefined keywords or patterns
  • Return a matching response
  • Provide a fallback response
  • Continue conversation until exit

Project Workflow

Enter message → Normalize text → Match a rule → Return response → Continue or exit

Technologies Used

PythonFunctionsConditionalsLoopsString processingConsole I/O

Scope & Notes

This is a rule-based chatbot. It does not use an LLM or generate open-ended AI responses.
