Project Overview

Inspect uploaded tabular data, summarize columns, check data quality, and explore distributions and correlations.

Key Features

  • Upload a CSV dataset
  • Inspect dataset shape, columns, and data types
  • Review descriptive statistics
  • Check missing values and duplicates
  • Explore distributions and correlations
  • Display analysis in a Streamlit dashboard

Project Workflow

Upload CSV → Inspect structure → Check data quality → Review statistics → Explore charts

Technologies Used

PythonPandasNumPyMatplotlibSeabornStreamlit

Scope & Notes

Analysis depends on the quality and representativeness of the uploaded dataset. Correlation does not establish causation.
